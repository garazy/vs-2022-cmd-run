# vs-2022-cmd-run

Adds an `Execute CMD` menu item to Visual Studio 2022 Solution Explorer for `.cmd` files.

Right-click a `.cmd` file in Solution Explorer and choose `Execute CMD`. The extension opens a normal `cmd.exe` window, sets the working directory to the selected file's folder, and runs the selected command file with `call`.

Open `CmdRun.sln` in Visual Studio 2022 to build or debug the extension. Debug starts Visual Studio with the experimental root suffix.
